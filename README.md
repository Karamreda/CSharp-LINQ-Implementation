# CSharp-LINQ-Implementation
This repository contains manual implementations of common LINQ methods in C#.

The idea behind this project is to go deeper into LINQ by rebuilding its methods from scratch instead of relying on the built-in LINQ methods provided by C#.
The purpose of this project is not to create a replacement for LINQ, but to understand how it works internally and learn the core concepts that LINQ is built on.
Throughout this project,

I focused on important C# concepts such as:

- Generics
- Delegates
- Lambda Expressions
- Extension Methods
- IEnumerable
- Yield Return
  
These concepts are considered some of the main building blocks behind LINQ.

--------------------------------------------------------------------------------------------------------------

Another important part of this project is that I didn’t rely on only one implementation approach. I experimented with different approaches depending on the method, such as:

- Using traditional loops
- Using yield return
- Using Generics
- Using Delegates and Lambda Expressions

----------------------------------------------------------------------------------------------------------------

The main goal of this project was to strengthen my C# fundamentals and understand what happens behind the scenes when we use LINQ, instead of being only a user of these methods.
Because understanding how things work internally helps us write cleaner, better, and more maintainable code.
